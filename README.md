# 🌦️ 台中天氣預報與 LINE 降雨自動提醒機器人

這是一個專為台中市民設計的 LINE 自動化天氣提醒機器人。
系統每天會定時自動抓取最新氣象數據，並在「降雨機率高於 40%」時，主動發送 LINE 訊息提醒出門帶傘，防止變成落湯雞。

# ✨ 核心特色
📊 氣象數據即時抓取：串接中央氣象署 API（或網頁爬蟲），即時獲取台中各區最新天氣與降雨機率預報。
☂️ 智慧防雨提醒：當預報之降雨機率 ≥ 40% 時，自動觸發警報，發送溫馨提醒語（例：「今天降雨機率 50%，出門記得帶把傘喔！」）。
⏰ 定時自動巡邏：內建排程定時任務（如每天早上 7:00），完全不需要手動點開程式，全自動在背景運作。
💬 LINE 訊息推播：整合 LINE Notify 或 LINE Messaging API，直接將通知精準送到使用者的手機中。

# 🛠️ 開發架構與技術
程式語言：Python 3
核心技術：網路爬蟲 (Requests / BeautifulSoup) 或 氣象 API 串接
訊息通知：LINE API 整合
自動化排程：APScheduler / GitHub Actions / Cron Job (視你使用的技術而定)
